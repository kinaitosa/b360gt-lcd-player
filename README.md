# B360 GT LCD 플레이어 사용 안내

발키리 B360 GT 수랭쿨러 LCD에서 로컬 영상을 반복 재생하는 비공식 Windows 플레이어입니다. `B360GT-LCD-Player-Portable.exe` 하나로 실행되며, Python이나 FFmpeg를 설치할 필요가 없습니다. CPU·GPU 온도와 팬 RPM을 조회하지 않으며, 펌프·팬·RGB 설정을 제어하지 않습니다.

## 다운로드

[GitHub Releases에서 포터블 실행 파일 다운로드](https://github.com/kinaitosa/b360gt-lcd-player/releases/latest)

## 지원 환경

| 항목 | 지원 범위 |
| --- | --- |
| 운영체제 | Windows 10/11 x64 |
| LCD | 발키리 B360 GT 중 USB ID가 `374A:A005`인 장치, Windows에서 WinUSB로 인식되어야 함 |
| 영상 | H.264(AVC)로 인코딩된 MP4 파일, 음성 없이 반복 재생 |
| 출력 | 480×480, 15 FPS 또는 30 FPS, 원본 영상 비율 유지 |

같은 B360 GT 이름이라도 USB ID가 다르면 이 버전의 지원 범위에 포함되지 않습니다. 장치 ID는 앱에서 자동으로 확인합니다. 직접 확인하려면 **장치 관리자 → 해당 USB 장치의 속성 → 자세히 → 하드웨어 ID**에서 `VID_374A&PID_A005`가 포함된 항목을 찾으세요. 장치 이름은 `Vk-Copl-08`로 표시될 수 있습니다. [Microsoft 하드웨어 ID 확인 안내](https://learn.microsoft.com/en-us/windows-hardware/drivers/install/hardware-ids)

## 사용 방법

1. 실행 파일을 보관할 폴더에 넣습니다. 자동 실행을 사용할 경우 나중에 옮기지 않아도 되는 폴더를 선택하세요.
2. Windows 작업 표시줄 오른쪽 트레이에서 **Myth.Cool을 완전히 종료**합니다. 기존 Python판이나 다른 LCD 제어 프로그램을 사용 중이라면 함께 종료하세요.
3. `B360GT-LCD-Player-Portable.exe`를 실행합니다.
4. **영상 열기**를 눌러 MP4 파일을 선택합니다. 영상은 LCD에서 반복 재생됩니다.
5. **프레임률**에서 **15 FPS** 또는 **30 FPS**를 선택합니다. 재생 중 바꾸면 영상이 처음부터 다시 시작되고, 선택한 값은 다음 실행에도 적용됩니다.

## 트레이와 자동 실행

- 창의 **×**를 누르면 창이 숨겨지고 재생은 계속됩니다. 작업 표시줄 오른쪽 **숨겨진 아이콘(∧)**에서 민트색 재생 아이콘을 왼쪽 클릭하면 창이 다시 열립니다.
- 아이콘을 우클릭해 **영상 리프레시**를 선택하면 영상을 처음부터 다시 재생합니다. **종료**를 선택하면 재생과 프로그램이 모두 종료됩니다.
- **Windows 로그인 시 자동 실행**을 체크하면 다음 로그인부터 트레이에서 시작하고 마지막으로 재생한 영상을 불러옵니다. 처음에는 **영상 열기**로 재생할 파일을 한 번 선택하세요.
- 자동 실행을 사용할 때는 Myth.Cool의 자동 실행도 꺼두세요. 두 프로그램이 함께 실행되면 LCD에 연결하지 못할 수 있습니다.
- 실행 파일을 옮기거나 이름을 바꾸려면 먼저 자동 실행을 끄고 앱을 종료하세요. 이동 후 새 위치에서 앱을 열고 자동 실행을 다시 켜면 됩니다.

## 주의점과 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| **LCD를 찾을 수 없습니다** | 장치 관리자에서 LCD가 인식되는지, 하드웨어 ID에 `VID_374A&PID_A005`가 있는지 확인하세요. 같은 ID의 LCD가 두 대 이상 연결된 경우 이 버전은 장치를 선택할 수 없습니다. |
| **LCD를 열 수 없습니다** | Myth.Cool과 다른 LCD 플레이어를 트레이에서 완전히 종료한 뒤 다시 시도하세요. 장치가 Windows에서 WinUSB로 인식되어야 합니다. |
| **MP4인데 열리지 않습니다** | MP4는 파일 형식입니다. 영상 코덱이 **H.264(AVC)**인지 확인하세요. HEVC(H.265)로 저장된 MP4는 H.264로 변환해야 합니다. |
| **영상이 끊깁니다** | 앱에서 15 FPS로 낮춰 보세요. 그래도 끊기면 영상 해상도를 낮춘 H.264 MP4로 다시 시도하세요. |
| **로그인 후 영상이 나오지 않습니다** | 저장된 실행 파일과 마지막 영상의 위치가 바뀌었는지 확인하세요. 영상을 옮겼다면 새 위치에서 다시 열어 주세요. |
| **Windows N에서 앱이 실행되지 않거나 영상을 열지 못합니다** | Media Feature Pack이 필요할 수 있습니다. [Microsoft 설치 안내](https://support.microsoft.com/en-us/windows/experience/platform-variants/media-feature-pack-for-windows-n) |

배포 실행 파일에는 디지털 서명이 없습니다. 신뢰할 수 있는 배포처에서 받은 파일만 실행하세요.

## 삭제

앱에서 **Windows 로그인 시 자동 실행**을 해제하고, 트레이 메뉴의 **종료**를 누른 뒤 실행 파일을 삭제하면 됩니다. 마지막 영상 경로와 프레임률 설정까지 지우려면 `%LOCALAPPDATA%\B360GT LCD Player` 폴더를 삭제하세요. 이 폴더에는 설정만 저장되며, 원본 영상 파일은 선택한 위치에 있습니다.
